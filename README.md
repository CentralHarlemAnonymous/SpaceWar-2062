2026 reimagining of the 1962 PDP-1 game SPACEWAR. I coded a version of this for the Mac in the mid-1990s but was never satisfied with the skills of the computer player and never distributed it commercially.

Now, armed with vastly greater processing power, I'm trying again. Uses Apple's CoreML for any computer players. Working towards network play as well.
